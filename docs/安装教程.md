# REFramework 与杰米的酒安装教程

适用于 Windows / Steam 版《Street Fighter 6》。整个安装过程只需要把 **一个 DLL 文件和一个文件夹**放进游戏目录，再启动游戏。

已经能够打开 REFramework 面板的安装，可以直接从第 3 步中的「安装 Mod」开始。

## 1. 下载并解压

先下载本 Mod 和 REFramework 两个压缩包。

**杰米的酒下载：**

- [直接下载本 Mod 压缩包](https://github.com/Overfloating0/Jamies-wine/archive/refs/heads/main.zip)。
- 也可以打开 [本 Mod 的 GitHub 页面](https://github.com/Overfloating0/Jamies-wine)，点击绿色 **Code** 按钮，再点 **Download ZIP**。
- 下载完成后，右键 ZIP 文件，选择 **全部解压缩**。打开解压后的 `Jamies-wine-main` 文件夹，找到 **`README.md` 和 `reframework` 文件夹**。

**REFramework 下载：**

- [直接下载官方 REFramework.zip](https://github.com/praydog/REFramework-nightly/releases/latest/download/REFramework.zip)
- 如果直接下载没有反应，打开 [官方发布页](https://github.com/praydog/REFramework-nightly/releases/latest)，向下找到 **Assets**，点击其中的 **REFramework.zip**。

这里链接的是官方持续更新的构建页面。当前使用的文件名就是 `REFramework.zip`，它支持《Street Fighter 6》，会自动识别游戏。

下载完成后，右键 ZIP 文件，选择 **全部解压缩**。打开解压后的文件夹，找到 **`dinput8.dll`**。框架包中还可能有 `reframework_revision.txt`，安装时只需取出 DLL。

页面上的 `VR.zip`、`csharp-api.zip` 和 `Source code` 都不是本 Mod 所需的框架安装包。

现在应当有两个解压文件夹：一个包含 REFramework 的 **`dinput8.dll`**，另一个包含杰米的酒的 **`reframework` 文件夹**。

## 2. 打开游戏所在的文件夹

1. 完全退出《Street Fighter 6》。
2. 打开 Steam，进入 **库**。
3. 右键 **Street Fighter 6**，点击 **管理 → 浏览本地文件**。
4. Steam 会直接打开游戏文件夹。在这里应当能看到 **`StreetFighter6.exe`**，接下来所有文件都放到这一层。

不需要手动寻找 Steam 安装位置，也不用在电脑上搜索游戏目录。

## 3. 复制框架和 Mod

保持第 2 步打开的游戏文件夹，依次完成下面两次复制。

**安装框架：**从 REFramework 解压文件夹中，复制 **`dinput8.dll`**，粘贴到 `StreetFighter6.exe` 旁边。

**安装 Mod：**从杰米的酒解压文件夹中，复制整个 **`reframework` 文件夹**，粘贴到同一个游戏文件夹。

如果已有同名 `reframework` 文件夹，内容会合并到里面。遇到同名文件需要替换时，先保留备份。框架已正常运行时，可以直接复制 Mod 文件夹。

完成后，应当是下面这样：

```text
Street Fighter 6/                 ← Steam 打开的游戏文件夹
├─ StreetFighter6.exe
├─ dinput8.dll                    ← 从 REFramework.zip 复制
└─ reframework/                  ← 从杰米的酒复制
   ├─ autorun/
   │  └─ jamieswine.lua
   └─ fonts/
      └─ NotoSansSC.ttf
```

检查两个位置即可：

- 打开游戏目录中的 `reframework → autorun`，能直接看到 **`jamieswine.lua`**。
- 打开游戏目录中的 `reframework → fonts`，能直接看到 **`NotoSansSC.ttf`**。

复制的是解压后的文件，不是 ZIP 压缩包。若文件位于 `reframework/reframework/`，应将里面那一层的内容移到外面的 `reframework` 中。`autorun` 中只保留一份本 Mod 的脚本。

到这里文件已经放好，**直接启动游戏即可**。源码、构建脚本和说明文档留在解压目录中，不需要运行任何安装程序或命令。

## 4. 在游戏里打开 Mod

1. 通过 Steam 启动游戏，等待进入主菜单。
2. 按键盘上的 **Insert** 键打开 REFramework 面板。键帽也可能写作 **Ins**；部分笔记本需要配合 Fn。
3. 在 REFramework 面板中找到 **Script Generated UI**，点击展开。它是脚本生成的功能界面；列表较长时向下滚动寻找。
4. 点击展开 **杰米的酒**，就能看到「总开关」「P1 果冻」「P2 果冻」等选项。
5. 进入本地训练或格斗之地的一对一对战。勾选 **总开关**，以及希望开启效果的 **P1 果冻 / P2 果冻**。
6. 再按一次 **Insert** 收起 REFramework 面板，即可正常游玩。

默认 **130 BPM、强度 0.75**。隐藏框架面板后，**F6** 切换效果，**F7** 关闭效果并恢复双方体型。

**ScriptRunner** 和 **Script Generated UI** 是两个不同栏目：前者管理脚本加载，后者显示 Mod 的控制面板。日常调节效果打开 **Script Generated UI** 即可。

*展开「杰米的酒」后可调节果冻强度、双方体型和节奏。更多设置见 [功能说明](功能说明.md)。*

## 卡在哪一步，就检查哪一项

### 看不到 REFramework 面板

先按 Insert / Ins；如果键盘上该按键与其他功能共用，尝试 Fn 组合键。仍无面板时，退出游戏，检查 `dinput8.dll` 是否与 `StreetFighter6.exe` 位于同一层，并确认下载来自上面的官方链接。

### 能打开框架，但没有「杰米的酒」

1. 在框架中展开 **ScriptRunner**。
2. 查看 **Known scripts** 列表里是否有 **`jamieswine.lua`**，并确认它已勾选。
3. 如果没有列出它，检查文件是否放在游戏目录的 `reframework/autorun/` 中，然后点击 **Reset scripts** 重新加载。
4. 回到 **Script Generated UI** 寻找「杰米的酒」。

文件放入 `autorun` 后会自动加载，通常无需点击 **Run script** 手动选择文件。`Reset scripts` 会重载框架中的 Lua 脚本；替换脚本后如果面板仍未更新，也可以退出并重新启动游戏。

如果 ScriptRunner 显示 **Last Script Error**，保留完整报错以便排查。若显示 **Online match detected**，先回到本地训练或本地对战，再检查脚本状态。

### 面板有了，但中文是方框

确认 `NotoSansSC.ttf` 位于游戏目录的 **`reframework/fonts/`**，补齐后重启游戏。

### 勾选后没有效果

进入支持的本地对局，等待双方角色出现；同时确认 **总开关** 和至少一方 **果冻** 已勾选。选角、加载或菜单阶段显示等待属于正常情况。

### 快捷键没有反应

先用 Insert 隐藏 REFramework 面板再按 F6 / F7。也可以直接使用 Mod 面板中的总开关和恢复按钮，或在「快捷键」中重新绑定。
