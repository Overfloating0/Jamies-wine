# 功能说明

首次安装请先阅读 [REFramework 与 Mod 安装教程](安装教程.md)。

![控制面板与角色体型效果](界面示例.png)

## 总开关与恢复

总开关控制果冻、自定义体型与投技缩矮。P1、P2 的果冻开关独立；关闭双方果冻后，仍可单独使用体型或缩矮效果。

主菜单可以预先设置参数并打开总开关，进入支持的对局后自动应用。离开对局时释放角色对象，参数继续保留。

**全部恢复 / F7** 关闭总开关、恢复双方比例并清空缩矮状态，保留体型和节奏预设。恢复失败时效果停止，面板显示提示，可再次点击恢复按钮重试。

## 节奏果冻

| 参数 | 说明 |
| --- | --- |
| 强度 | 0—1，默认 0.75；数值越高，形变越明显 |
| BPM | 默认 130 |
| 每周期拍数 | 0.5、1、2 或 4，默认 1 |
| 节拍偏移 | 正值延后，负值提前，单位为毫秒 |
| 固定周期 | 可选择 0.65 秒周期 |

周期计算为 `60 ÷ BPM × 每周期拍数`，有效范围为 0.2—3 秒。修改 BPM、拍数或偏移后，点击 **应用节奏与偏移**。

**将当前时刻设为节拍基准** 可以对齐最矮点或周期起点。要精确对齐当前时刻，先把偏移设为 0。**从现在重启周期** 将当前时刻设为周期起点。

果冻按真实时间推进。暂停、慢放、快放和命中停顿不改变周期；画面停止更新时，恢复显示后接入当前相位。P1、P2 共用节拍，退场、换回合、临时关闭效果保留基准；重载脚本或重启游戏后重新计时。

## 自定义体型

P1、P2 分别设置，默认关闭：

- **身高**：50%—150%。
- **体宽**：50%—150%，同时调整宽度与厚度。
- **体型恢复 100%**：只重置该方的自定义比例，果冻和投技缩矮继续按各自设置运行。

自定义体型、投技缩矮和果冻效果相乘。较小身高配合缩矮及高强度果冻时，形变会更明显。不同角色的服装、头发和饰品可能呈现不同效果。

## 桑吉尔夫投技 / 踩踏缩矮

开启后，识别到的桑吉尔夫投技按下列档位缩小对手：

| 累计次数 | 身高比例 |
| --- | --- |
| 1 | 85% |
| 2 | 70% |
| 3 | 50% |
| 4 及以上 | 30% |

SA3 / CA 计两次；SA2 仅砸地派生计数。身高降至 50% 或以下后，能量踩踏每次有效命中再减少 1 个百分点，最低 30%。防御和落空不计入踩踏缩矮。

**重置双方缩矮** 清空累计次数并恢复该项比例。新回合和训练重置也会清空缩矮状态。回放回退根据已记录事件重建比例。特殊演出中的缩矮时机可能与画面冲击点略有差异。

## 杰米酒数联动

**强度随杰米酒数增加** 默认关闭。开启后，双方果冻共用以下强度：

```text
实际强度 = min(1, 基础强度 + 0.03 × 双方杰米酒等级之和)
```

基础强度为 0.75 时，一名四酒杰米对应 0.87，两名四酒杰米对应 0.99。非杰米角色贡献为 0。

面板显示双方读数与实际强度。特殊状态下酒等级无法识别时，使用基础强度；SA2 临时状态可能触发这一回退。联动只调整视觉形变，不修改游戏酒等级。

## 快捷键与配置

- 默认 F6 切换总开关，F7 全部恢复。
- 可绑定 F1—F12，也可禁用；两个功能使用不同按键。
- 隐藏 REFramework 界面后生效，长按触发一次，同时按下时恢复优先。
- 默认中文，可切换 English；字号可在 18—40 之间调整，默认 40。
- 参数自动保存至 `reframework/data/SF6Jelly_settings.json`。
- 默认加载后手动开启效果；可勾选 **加载脚本时自动恢复已保存的总开关**。

## 常见问题

**面板显示“等待角色”**

进入本地训练、格斗之地一对一对战或回放，并等待角色载入。选角、加载与菜单阶段会暂停效果写入。

**中文显示方框**

检查 `reframework/fonts/NotoSansSC.ttf` 是否存在，再重启游戏。

**快捷键没有反应**

先隐藏 REFramework 界面，检查快捷键是否被禁用或与其他功能冲突。

**需要排查运行异常**

在 **高级：规则与诊断 → 保存诊断** 导出日志，文件位置显示在面板中。出现明显卡顿或异常形变时，可先按 F7 恢复。

**停用 Mod**

先按 F7 恢复并退出游戏，再将 `reframework/autorun/jamieswine.lua` 移到 `autorun` 之外的备份目录。
